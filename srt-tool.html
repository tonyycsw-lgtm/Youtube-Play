SRT 字幕產生工具

給老師使用：從 YouTube 抓取或貼上英文字幕，一鍵翻譯成繁體中文，逐句修改後匯出 SRT 檔，學生端即可看到中英對照字幕。

1選擇來源 2翻譯繁體中文 3逐句編輯 4匯出 SRT 5產生詞匯表

步驟 1選擇字幕來源

貼上 YouTube 網址後按「從 YouTube 抓取字幕」。若自動抓取被 YouTube 限制（目前常見），請按「開啟影片轉錄稿」→ 在 YouTube 點「⋯」→「顯示轉錄稿」→ 全選複製 → 貼到下方欄位解析。

取得 YouTube 轉錄稿的步驟（自動抓取被限制時請照做）

  1. 按上面「開啟影片轉錄稿」，會在新分頁開啟該 YouTube 影片。
  2. 在影片標題下方、分享 按鈕旁邊，點 ⋯ 更多。
  3. 在跳出的選單選 顯示轉錄稿，右側會出現字幕逐句面板。
  4. 在轉錄稿面板右上角點 ⋯，確認 切換時間戳記 為「開啟」（一定要有時間碼，否則無法定位時間）。
  5. 點一下轉錄稿文字區，按 Ctrl+A 全選、Ctrl+C 複製。
  6. 回到本頁，把內容貼到下方「貼上字幕文字」欄位，按「解析貼上的文字」。

提示：若影片沒有提供任何字幕，YouTube 就不會顯示「顯示轉錄稿」，此時只能手動聽打或自行上傳 SRT。

建議做法：貼上 YouTube 轉錄稿（或 SRT 全文）／上傳現有 SRT

步驟 2翻譯成繁體中文

把英文字幕整批翻譯成繁體中文。翻譯使用免費服務 MyMemory；個別句子翻譯不佳可直接在下方修改，翻譯失敗的句子會留空待手動補上。

填入聯絡信箱可把 MyMemory 免費額度從每日約 5,000 字提升至 50,000 字。翻譯後仍可逐句修改。

步驟 4匯出 SRT

預覽並下載 SRT 檔。下載的檔案含 UTF-8 BOM，可直接用 Windows 記事本開啟。

下載後把檔案放到專案 subtitles/ 資料夾，檔名為 {影片 ID}.srt，學生端即自動使用（本工具偵測到的 ID 會自動帶入檔名）。也可在 programs.json 的該節目加 "srt": "路徑.srt" 指定其他檔名。

步驟 5產生詞匯表（選用）

把字幕切成約 N 秒的片段，列出每段出現的英文詞匯。可翻譯成中文、刪除不要的詞，匯出 JSON 放到專案 vocabulary/，學生端播放頁就會顯示詞匯面板。

檔名：{影片 ID}.json，放到專案 vocabulary/ 資料夾。播放頁會自動讀取；沒有 JSON 時會自動抽取英文詞（無中文）。
